# Tools and Technologies

## Overview

SUTMS is built using open-source networking, intrusion detection, security monitoring, firewall, threat intelligence, and system monitoring technologies.

## Technology Stack

| Category | Technology | Purpose |
|---|---|---|
| Operating System | Ubuntu Linux | Base operating environment |
| IDS / IPS | Suricata | Network traffic inspection and threat detection |
| SIEM | Wazuh | Security monitoring, log analysis, and alert management |
| Firewall | iptables | Network traffic filtering and enforcement |
| System Monitoring | Glances | CPU, memory, disk, and network monitoring |
| Threat Intelligence | STIX / TAXII | Structured threat intelligence exchange |
| Automation | Python / Shell | Supporting automation and utilities |
| Virtualization | Virtual Machine | Controlled development and testing environment |

## 1. Ubuntu Linux

Ubuntu Linux provides the base operating environment for SUTMS. It provides:

- Linux networking capabilities
- System and service management
- Package management
- Firewall integration
- Process and resource management

## 2. Suricata

Suricata is the primary network IDS/IPS component. Suricata generates security events that can be processed by the centralized monitoring layer.

### Main Functions

- Packet inspection
- Protocol analysis
- Signature-based detection
- Intrusion detection
- Intrusion prevention
- Security-event generation
- Network security monitoring


## 3. Wazuh

Wazuh provides centralized security monitoring and event analysis. Wazuh provides centralized visibility into security events generated by the system.

### Main Functions

- Log collection
- Security-event analysis
- Alert generation
- Event correlation
- Security monitoring
- Active response
- Dashboard visualization


## 4. iptables

iptables provides the firewall and network enforcement layer.

### Main Functions

- Packet filtering
- Network access control
- Traffic restriction
- IP-based blocking
- Firewall rule management
- Security-event enforcement

## 5. Glances

Glances is used for monitoring system resources. It helps evaluate the resource requirements of the SUTMS environment.

### Monitored Resources

- CPU utilization
- Memory utilization
- Disk usage
- Network activity
- Running processes
- System load


## 6. STIX / TAXII

SUTMS supports the use of standardized threat intelligence through STIX and TAXII. STIX provides a structured format for representing cyber-threat intelligence. TAXII provides a standardized mechanism for exchanging cyber-threat intelligence. Together, they can be used to support threat-intelligence collection and integration.

## 7. Python and Shell

Python and Linux shell utilities are used for supporting:

- Automation
- System administration
- Data processing
- Testing
- Configuration management
- Project utilities

## 8. Virtualization

The project uses a virtualized Linux environment for controlled development and testing.

Virtualization provides:

- Network isolation
- Repeatable testing
- Controlled traffic generation
- Resource allocation
- Safe security-event simulation
